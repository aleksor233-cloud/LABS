1.Словник англійських термінів 

CLI (Command Line Interface) — A text-based user interface used to view and manage computer files and execute commands.

Shell — A command-line interpreter that translates user-entered text commands into instructions for the operating system kernel.

Bash (Bourne Again Shell) — The default command-line shell and script language for most Linux distributions.

Prompt— A sequence of characters displayed on a command line to indicate that the shell is ready to accept input.

Command — An executable program or built-in directive given to the computer to perform a specific task.

Option (Flag) — A parameter passed to a command (usually preceded by `-` or `--`) to modify its standard behavior.

Argument — The target or data (such as a filename or path) upon which a command operates.

Variable — A named storage location in memory used by the shell to retain data and system configuration state.

Environment Variable** — A dynamic variable that affects the behavior of processes and shell sessions across the operating system.

Alias — A user-defined shortcut or custom nickname used to execute a longer command sequence.

Quote (Quoting) — Characters (`"`, `'`, `` ` ``) used to control how the shell interprets special characters, whitespace, and expansion.

Control Statements — Operators (`;`, `&&`, `||`) used to control the execution order and condition of multiple commands.

2.Завдання для попередньої підготовки

 2.1. Визначення основних поняття
Командний інтерпретатор — це програма, яка зчитує введений користувачем текст, розпізнає команди та передає їх на виконання операційній системі.

Оболонка (Shell) — середовище-посередник між користувачем і ядром ОС, що надає інтерфейс командного рядка (CLI) або графічний інтерфейс (GUI).

Команда — виконуваний файл або вбудована у Shell інструкція, яка змушує комп'ютер виконати визначену дію.

 2.2. Відповіді на питання підготовки
1. Інформація у рядку запрошення (prompt):  
   У замовчуваній формі на кшталт `sysadmin@localhost:~$` показується:
   * Ім'я користувача (`sysadmin`).
   * Назва ПК/хоста (`localhost`).
   * Поточна робоча папка (`~` — домашній каталог `/home/sysadmin`).
   * Символ привілеїв (`$` — звичайний юзер, `#` — root).

2. Навіщо потрібні параметри та аргументи:
   Параметри (options) змінюють режим роботи команди (наприклад, вивід у довгому форматі чи відображення прихованих файлів).
   Аргументи вказують, до якого саме об'єкта (файлу або папки) застосовується команда.

3. Призначення команди `ls` та приклади:  
   Призначена для перегляду вмісту каталогів.
   * `ls -a /home` — виводить всі файли, в тому числі приховані.
   * `ls -lh /var/log` — показує файли у довгому форматі з розмірами у зручному вигляду (КБ, МБ).
   * `ls -lt /etc` — сортує файли у `/etc` за часом останньої зміни.

4. Використання історії команд:  
   Історія (`history`) дозволяє повертатися до раніше введених команд стрілками Вгору/Вниз або комбінацією `Ctrl + R`. Це значно зекономить час на повторний ввід довгих команд.

5. Призначення команди `echo`:  
   Виводить текстовий рядок або значення змінної у термінал.

6. Змінні в Bash: 
   Збережені значення у пам'яті. Бувають:
   Локальні — діють тільки в поточному вікні/сесії Bash.
   Змінні оточення (Environment)** — доступні для всіх дочірніх програм та процесів у цій сесії.

7. Команди `env`, `export`, `unset`: 
   * `env` — виводить усі змінні оточення.
   * `export` — робить локальну змінну змінною оточення.
   * `unset` — видаляє змінну з пам'яті.

8. Довідкові команди:
   `man <команда>`, `<команда> --help`, `help <вбудована_команда>`, `info`.

5. Відповіді на контрольні запитання

 1. Які типи команд існують в оболонці Bash?
В оболонці Bash є чотири основні типи команд:

Внутрішні (built-in) — команди, що вбудовані в саму оболонку.

Зовнішні — це окремі програми (файли), які оболонка шукає в системі.

Псевдоніми (aliases) — скорочені назви для довших команд, які ми можемо створювати самі.

Функції — створюються з існуючих команд для створення нових інструкцій.

 2. Що таке змінні оточення? Які вони бувають. Як їх можна переглянути в терміналі?

Змінні потрібні для того, щоб зберігати дані в пам'яті та змінювати поведінку оболонки Bash. Загалом змінні бувають двох типів: локальні (діють тільки в поточному вікні) та змінні оточення (environment). Змінні оточення глобальні і передаються всім програмам у системі. Переглянути їхній список в терміналі можна за допомогою команди env або printenv.

 3. Опишіть змінну $PS1. Як в терміналі переглянути її вміст?

Змінна $PS1 (Prompt String 1) відповідає за зовнішній вигляд основного рядка запрошення в терміналі (того самого, що показує ім'я користувача, систему та поточну папку). Щоб переглянути її поточний вміст (формулу вигляду), потрібно ввести команду echo $PS1.

 4. Як можна змінити значення змінної $PS1? Що при цьому відбудеться в рядку запрошенні в bash. Як змінити значення цієї змінної не на поточний сеанс, а за замовчуванням?

Тимчасово змінити значення можна прямо в терміналі, просто присвоївши нове: PS1="[my_linux]\$ ". Одразу після натискання Enter рядок запрошення змінить свій вигляд на новий. Але як тільки ми закриємо термінал, налаштування скинуться. Щоб змінити його за замовчуванням (назавжди), потрібно записати команду export PS1="[my_linux]\$ " у прихований конфігураційний файл нашого користувача — ~/.bashrc.

 5. Для чого використовують лапки в оболонці Bash?

Лапки потрібні, щоб повідомити системі, що текст всередині них треба обробляти особливим чином (наприклад, не розривати слова через пробіли) або взагалі ігнорувати спецсимволи. Існує три типи:   подвійні (" ") — зберігають текст, але дозволяють виводити значення змінних всередині.   одинарні (' ') — повністю сприймають все всередині як звичайний текст (ігнорують змінні).   зворотні (` `) — виконують команду, яка написана всередині них.

 6. Для чого використовують інструкції керування, які їх види Ви знаєте?

Вони дозволяють запускати одразу декілька команд в одному рядку або ставити умови для їх виконання. Види, з якими працювали:   Крапка з комою (;) — просто виконує команди по черзі.   Подвійний амперсанд (&&) — друга команда виконається тільки тоді, коли перша завершиться без помилок.   Подвійний пайп (||) — друга команда запуститься тільки у випадку, якщо перша видала помилку.   

 7. В чому різниця якщо в кінці рядку запрошення bash стоїть символ $ чи #?

Як можна було побачити на практиці, символ в кінці рядка запрошення показує наші права в системі. Символ $ означає, що ми зайшли як звичайний користувач із базовими правами (як у наведеному прикладі рядка sysadmin@localhost:~$). А от символ # означає, що ми працюємо від імені суперкористувача (root), тобто маємо повні права адміністратора і можемо вносити будь-які зміни в систему.   

 8. Яке призначення команд whereis та locate? Яка між ними відмінність?

Обидві команди шукають файли, але роблять це по-різному:whereis використовується для пошуку специфічних системних файлів — вона шукає тільки виконувані файли (програми), їхній початковий код та файли довідки (man-сторінки) у стандартних папках Linux.locate шукає взагалі будь-які файли чи папки по всій системі. Вона працює дуже швидко, тому що шукає не на самому диску, а у спеціальній підготовленій базі даних. Але через це є мінус: якщо файл тільки-но створили, locate його не знайде, поки ми не оновимо її базу даних командою updatedb.
