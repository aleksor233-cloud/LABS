ЗВІТ ДО ЛАБОРАТОРНОЇ РОБОТИ №4 з дисципліни: «Операційні системи»

Тема: “Команди Linux для управління процесами”.  
Мета роботи:
  Отримання практичних навиків роботи з командною оболонкою Bash.   
  Знайомство з базовими командами для управління процесами.   

1. Словник термінів
  Process (Процес) — програма, яка запущена і працює в системі.   
  PID (Process ID) — ідентифікатор процесу.   
  PPID (Parent Process ID) — ідентифікатор батьківського процесу (якщо процес був запущений іншим процесом).   
  Job (Завдання) — процес, яким керує системна оболонка.   
  Foreground (Передній план) — завдання, яке займає вікно терміналу до моменту свого повного завершення.   
  Background (Фоновий режим) — завдання, яке працює у фоні і не займає вікно терміналу, дозволяючи системі миттєво повернути підказку оболонки.   
  ps — утиліта для створення статичного знімка поточних процесів у системі.   
  top — команда, що відображає процеси та навантаження системи в режимі реального часу.

2. Завдання попередньої підготовки

  2.1. Для моніторингу стану процесів використовують команди ps та top. Переглянути їх можливі параметри можна в офіційній документації оболонки (наприклад man ps), при цьому команда ps підтримує три різні формати параметрів: у стилі Unix, у стилі BSD та довгі параметри GNU.

  2.2. Ні, команда ps не може відслідковувати стан у реальному часі. Вона відображає інформацію лише для специфічного моменту часу.  

  2.3. За замовчуванням команда top сортує процеси на основі значення %CPU. Для зміни параметру сортування під час роботи програми необхідно натиснути клавішу f, яка дозволяє обрати інше поле для впорядкування. 

  2.4. Для завершення роботи процесів використовуються команди kill (зупиняє процес за його номером PID) та killall (зупиняє процеси за їхньою назвою, підтримуючи символи підстановки).   

3.Хід роботи:

Пункт 1. Початкова роботаЯ запустив ОС Ubuntu у VirtualBox та відкрив термінал.

Пункт 2. Аналіз та відповіді на питання
  Директорія /proc: Вивів її вміст командою ls /proc. Це псевдофайлова система в оперативній пам'яті, яка містить інформацію про активні процеси (нумеровані папки) та конфігурацію системи (наприклад, cpuinfo).  

  Сеанси користувачів: Для перегляду використав команди w, who або перший рядок утиліти top.   

  Комбінації клавіш: Ctrl+C — примусово зупиняє програму, Ctrl+D — завершує сеанс (EOF), Ctrl+Z — призупиняє процес на передньому плані та ховає його у фон
   
  Типи процесів: Звичайний процес блокує термінал до завершення роботи. Фоновий процес запускається через додавання & у кінці команди і дозволяє далі користуватися командним рядком.   

  Управління завданнями: jobs показує список поточних завдань, bg %n переводить призупинене завдання у фоновий режим, fg %n повертає його на передній план.   

Пункт 3. Практика роботи з процесами

Запустив команду top для динамічного моніторингу системи.   Натиснув Ctrl+Z, чим призупинив виконання top.   Вивів базову інформацію про процеси за допомогою команди ps.

Виконав 5 варіантів ps:
ps -e — всі запущені процеси.   
ps -f — вивід з додатковою інформацією (UID, PPID, час).   
ps -u root — лише процеси користувача root.   
ps -l — довгий формат зі статусом (S) та пріоритетом (PRI).   
ps -ef — детальна таблиця всіх процесів системи.  

Ввів команду jobs і побачив свій призупинений процес top.   
Командою fg %1 вивів top на екран, знову зупинив через Ctrl+Z, а потім командою bg %1 змусив його працювати у фоні.   
Повністю завершив роботу цього процесу утилітою killall top.
